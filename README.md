# Melofy
Melofy is a web app that generates custom Spotify playlists based on your listening habits. By analyzing your top tracks, artists, and genres, Melofy uses Spotify's Web API to create a unique playlist tailored just for the you.

## Features
Spotify OAuth Integration – Log in securely using your Spotify account.
Personalized Data – Fetch your top tracks, artists, and genres for the past 4 weeks, 6 months, or 1 year.
Smart Playlist Creation – Dynamically generate playlists using random combinations of your most-listened content.
Asynchronous API Chaining – Automatically create a new playlist and populate it with recommended tracks.
Spotify-like UI – Clean Spotify-inspired interface with animated transitions, loading spinners, and responsive design.

## Tech Stack
Frontend: Angular, TypeScript, HTML, CSS
APIs: Spotify Web API (OAuth 2.0, search, top items, playlist endpoints)
